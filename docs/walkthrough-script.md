## 1. Native Windows Screen-Recording Instructions

Follow these exact steps to record your 2–3 minute walkthrough video on Windows without installing third-party software:

### Method A: Built-in Windows Snipping Tool (Recommended)
1. Press `Windows Key + Shift + R` (or open **Snipping Tool** from the Start Menu and select the Video Camera icon).
2. Click **+ New** and drag a rectangle over your browser window (or record full screen at 1920x1080).
3. Ensure your microphone is toggled **On** in the Snipping Tool top bar.
4. Click **Start** (a 3-second countdown will begin).
5. Follow the timed walkthrough script below.
6. Click the red **Stop** button when finished.
7. Click the save icon to export your `.mp4` video (e.g., save as `Growify_Digital_Walkthrough.mp4` in `C:\growify\submission\`).

### Method B: Xbox Game Bar
1. Open your browser to `http://127.0.0.1:3000/`.
2. Press `Windows Key + G` (or `Windows Key + Alt + R` to instantly start recording).
3. Unmute your microphone using the floating widget.
4. Run through the script. Press `Windows Key + Alt + R` to finish.
5. The video will be saved in `C:\Users\<user>\Videos\Captures`. Copy it to `C:\growify\submission\`.
